# PCOS Frontend

Personal Cognitive Operating System - Web UI

## 设计理念

- **温暖友好** - 柔和的暖色调，像个人日记本
- **移动优先** - 响应式设计，手机优先
- **中文界面** - 所有文本使用中文
- **信任伙伴** - 像可信赖的朋友，而非冷冰冰的 AI 工具

## 技术栈

- Next.js 14
- Tailwind CSS
- TypeScript
- Lucide Icons

## 开发

```bash
cd frontend
npm install
npm run dev
```

访问 http://localhost:3000

## 页面

- **首页** - 做决策（主要交互页面）
- **历史** - 查看过去的决策记录
- **分析** - 价值观画像、决策模式洞察
- **设置** - 编辑价值观、偏好、关注领域

## 设计风格

- 色彩：暖色调（奶油色、陶土色、鼠尾草绿）
- 字体：Noto Sans SC + Noto Serif SC
- 圆角：大圆角（2xl, 3xl）
- 阴影：暖色调阴影
- 动画：柔和的淡入和滑入效果
