# PCOS Frontend V2

温暖可爱风（Kawaii Soft UI）决策伙伴界面

## 设计风格

- **配色**: 暖粉 + 蜜桃 + 嫩绿
- **字体**: Nunito + ZCOOL KuaiLe
- **圆角**: 20-30px
- **动画**: 柔和弹跳、浮动、滑入
- **背景**: 粉+绿点阵纹理

## 页面

| 页面 | 路由 | 功能 |
|------|------|------|
| 首页 | `/` | 输入问题、PCOS 分析、记录决定 |
| 回忆录 | `/history` | 查看历史决策、筛选、统计 |
| 洞察 | `/analysis` | 价值观画像、决策模式、关键洞察 |
| 设置 | `/settings` | 编辑价值观、偏好、关注领域 |

## 启动

```bash
cd frontend-v2
npm install
npm run dev
```

访问 http://localhost:3000
