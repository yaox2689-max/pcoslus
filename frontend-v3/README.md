# PCOS Frontend V3

Warm earth-tone, hand-crafted aesthetic — ResumeAst Design System

## Design

- **Palette**: Caramel #C4956A, Sage #A8B5A0, Coral #E8937A
- **Typography**: Plus Jakarta Sans (headings) + Outfit (body)
- **Radius**: 16-20px cards, full-radius pills
- **Shadows**: Warm-tinted, never harsh
- **Dark mode**: Built-in toggle, warm dark palette
- **Animations**: Scroll reveals, staggered fade-up, bubbleIn

## Pages

| Route | Page | Function |
|-------|------|----------|
| `/` | 决策 | Ask PCOS, record decision |
| `/history` | 回顾 | Past decisions with filters |
| `/analysis` | 洞察 | Value radar, patterns, insights |
| `/settings` | 设置 | Edit values, preferences |

## Start

```bash
cd frontend-v3
npm install
npm run dev
```
